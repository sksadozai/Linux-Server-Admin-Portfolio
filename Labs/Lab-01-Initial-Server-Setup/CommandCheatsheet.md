# Command Cheatsheet: Basics & Users

| Purpose | Command |
|---------|---------|
| Print Working Directory (where am I?) | `pwd` |
| Change Directory | `cd /path/to/folder` |
| List files and folders with details | `ls -l` |
| Create a new directory | `sudo mkdir /folder_name` |
| Create a new empty file | `sudo touch filename.txt` |
| Create a new user (interactive) | `sudo adduser <username>` |
| View the end of a text file | `tail -n 5 /path/to/file` |
