# Linux Server Administration Portfolio

This repository documents my progression from basic Linux usage to administrative-level server management, tailored for IT Helpdesk and System Administrator roles. 

Having previously mastered Windows Active Directory, File Servers, and Backups, this project bridges the gap to Linux environments. Each module in the `Labs/` directory represents a hands-on daily lab, complete with a configuration guide, a command cheatsheet, and visual proof of execution via screenshots.

## Repository Structure
- **Labs/**: Contains individual folders for each daily lab.
  - `README.md`: Explains the lab's objective, scenario, and step-by-step configuration.
  - `CommandCheatsheet.md`: A quick reference for the commands utilized in the lab.
  - `screenshots/`: Visual verification of the lab steps.

## Skills Demonstrated
* Initial Server Provisioning & SSH Hardening
* User, Group, & Access Control (sudoers)
* File System Management, ACLs, & LVM
* Service Management (Systemd) & Package Repositories
* Network Configuration & Troubleshooting
* File Sharing (Samba/NFS) for Cross-Platform Environments
* Automated Backups & Cron Scheduling
